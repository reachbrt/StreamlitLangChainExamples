# Git Identity Options

## Use Your Real Name (Default)

```bash
git config --local user.name "BharatKumar Subramanian"
git config --local user.email "reachbrt@gmail.com"
```

## Use GitHub's Private Email (For Privacy)

1. Go to GitHub Settings → Emails
2. Check "Keep my email addresses private"
3. Use the provided no-reply email:

```bash
git config --local user.name "Bharat Kumar Subramanian"
git config --local user.email "username@users.noreply.github.com"
```

## Check Your Current Setting

```bash
git config user.name
git config user.email
```
